# STREAM CLIMBER

**配信で、どこまでも。** マイクとケーブルで8つの配信世界を登る、オリジナルの物理クライミングゲーム。
添付デザインをもとに、青い空、シアンと紫の光、白い配信カプセル、銀髪のライバー、配信塔を表現しています。
IRIAMの非公式ファン作品であり、公式ロゴ・公式ギフト・他ゲームの素材は使用していません。

## 操作

1. マウスまたは指を**押したまま足場の上端を狙う**。遠いほどマイクが伸びます。
2. マイクが掛かり「LOCK」が出たら、**押したまま身体へ近づける**とケーブルを巻き取って上昇します。
3. 掛けたまま身体の左・右へ指をずらすと**振り子回転**。縁の外へ振り上げてください。
4. 離すとマイクが外れます。慣性を使い、次の足場へ投げ直します。

床や足場の下面には固定されません。壁を貫通して狙うことはできないため、縁を回り込むように操作してください。
キーボード不要。スマホ横持ち推奨、縦持ち対応。PAUSEまたはEscapeで一時停止します。
各エリア先頭の旗の足場に着地するとチェックポイントを保存します。保存地点の3m下まで落ちると自動で戻り、一時停止メニューの「チェックポイントへ戻る」からも復帰できます。
復帰しても経過時間・最高到達・落下記録は引き継ぎます。復帰を使ったクリアは専用のベストタイムに記録します。
最初の登攀は画面の黄色い輪と4段階の操作ガイドで練習できます。一時停止 → 遊び方 →「操作ガイドをもう一度」で再表示できます。

## 開発

Node.js 22以降を使用してください。

```sh
npm ci
npm run dev -- --port 5183 --strictPort
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
```

Edgeがインストールされた環境で、開発サーバーを起動したまま次を実行します。

```sh
npm run test:browser
```

ブラウザ設定は`playwright.config.ts`です。別環境では`channel`をインストール済みブラウザに合わせてください。
WindowsのOneDriveでesbuildが親ディレクトリのAccess deniedを返す場合は、フォルダーの権限を確認して通常のターミナルで実行してください。
設定読込だけで失敗する場合は、`npm run dev -- --port 5183 --strictPort --configLoader runner`、`npm test -- --configLoader runner`でも実行できます。
開発サーバー起動後の`node scripts/qa-route.mjs`は109区間を物理入力で検査します。各試行の開始位置を復元し、対象またはその上の足場への着地を探索する検査で、連続した通し攻略や人間の操作時間の保証ではありません。結果と再現用の操作パターンは`test-results/route-report.json`に出力します。

## 構成

| ファイル | 責務 |
| --- | --- |
| `src/App.tsx` | タイトル・HUD・設定・再開・確認・結果画面 |
| `src/style.css` | スマホ縦横・safe area・タイトルデザイン |
| `src/game/engine.ts` | Rapier初期化、120Hz固定物理、入力、カメラ、ライフサイクル |
| `src/game/renderer.ts` | Canvas描画、カリング、背景・キャラクター・エフェクト |
| `src/game/model.ts` | 型、独立した物理パラメータ、落下計測 |
| `src/game/stage.ts` | 地形・8エリア定義 |
| `src/game/save.ts` | 保存とスキーマ検証 |
| `src/game/audio.ts` | ユーザー操作後に開始するWeb Audio BGM・SE |

ReactはUIを担当し、物理と描画は独立しています。HUD更新は10Hz、物理は1/120秒・追いつき最大12ステップ、DPR上限1.8です。マイクとカプセルにCCDを有効化しています。ロープ最大長はRapier Rope Joint、巻き取りは張力と減衰、掴みは接触後のFixed Jointで計算します。[Rapier公式CCD説明](https://rapier.rs/docs/user_guides/javascript/rigid_body_ccd/)

## ステージ編集

`ZONES`が8エリアの進捗範囲・名称・色を定義します。`createStage()`が決定的な座標列を生成します。
足場データは`x/y/w/h/angle/kind/zone/slippery`。高さ240mの連続ワールドで、エリア切替ロードはありません。
イベント付近と終盤ではルートを横へずらし、落下時に下の足場を外れる余地を作っています。
既存の座標を保ち、エリアごとに広い休息足場・交互の足場幅・細い足場のリズムを設定しています。`CHECKPOINTS`は各エリア先頭の平坦な足場、`ZONE_TIPS`はエリアごとの操作ヒントです。
単体テストは隣接足場の最短縁間距離がマイクの射程内にあることを確認します。ただしこれは全区間の実プレイ攻略保証ではありません。

## アセット

`public/assets/sky-tower.png`はタイトル、`studio-sky.png`はゲーム背景、`player.png`はキャラクターです。
ゲーム内画像のURLは`renderer.ts`、タイトルは`style.css`で設定します。
キャラクター画像の周囲は描画用のシルエットクリップで除外しています。完全な透過素材に差し替える際はクリップを調整・撤去してください。
読込失敗時はCanvasの簡易描画にフォールバックします。
タイトルではゲーム背景とキャラクターを読み込まず、開始後に非同期で読み込みます。約4.74MBの画像リクエストを開始後へ移し、メインUIとゲームエンジンのコードも分離しています。
Barlow Condensedフォントは`public/assets/fonts`へ同梱し、ライセンスは同フォルダーの`OFL.txt`です。実行時の外部API・CDN・ログインは不要です。
画像は内蔵画像生成ツールを使用しました。制作プロンプトは`ASSETS.md`に記載しています。

## セーブ

キーは既存の`stream-climber-save-v1`を維持し、保存形式はversion 2、設定は`stream-climber-settings-v1`。
プレイヤー・マイクの位置/速度/回転/角速度、ケーブル長、固定位置、経過時間、最高到達、落下数/最長/合計距離、継続中の落下開始点、クリア、ベストタイム、version、更新時刻を保存します。
追加でチェックポイントのエリア、復帰回数、練習ガイドの進行、復帰ありのベストタイムを保存します。v1は読み込み時に移行し、位置・速度・落下集計・ベストタイムを保持します。過去の最高到達より下にあるチェックポイントを引き継ぎます。
1秒ごと、およびチェックポイント獲得・復帰・一時停止・visibilitychange・beforeunloadで保存。破損データや不明なバージョンは勝手に削除せず、安全に新規開始を案内します。NEW GAMEは確認後に現在の挑戦とチェックポイントを上書きし、両方のベストタイムを維持します。
ブラウザを閉じた直前の保存をOSが省略する場合があり、通常時は最大約1秒前の状態になります。

## デバッグ / 配信

- `?debug=true`：座標・速度・FPS・ケーブル長・物理Hz、エリア選択、ゴール検証。
- F1 / F5：衝突形状、F2：次エリア、F3：現在エリア先頭、F4：低速、F6：FPS設定。
- デバッグでは記録を保存しません。ブラウザテスト用の`window.climberDebug`もこのモードだけで有効です。
- `?stream=true`：操作ヒント・高度・エリア名を省いた配信向け表示。

## GitHub Pages

`base: './'`のためリポジトリ名配下でも動作します。ルーティングを使わず、再読み込みも可能です。

1. GitHubにリポジトリを作成し、このフォルダーをpushします。
2. Settings → Pages → Sourceを**GitHub Actions**にします。
3. `main`へpush、またはDeploy STREAM CLIMBERワークフローを手動実行します。

`.github/workflows/deploy.yml`がnpm ci・型チェック・lint・単体テスト・build後に`dist`を公開します。
公開先: https://altogrow-ir.github.io/STREAM-CLIMBER/
リポジトリ: https://github.com/altogrow-IR/STREAM-CLIMBER
